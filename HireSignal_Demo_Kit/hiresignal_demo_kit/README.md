# HireSignal Demo Kit

Synthetic test documents for demonstrating the HireSignal AI Job-Fit Scorer.

## Contents
- `Resumes/` - 2 synthetic resumes. Priya is designed as a strong backend match; Arjun intentionally contains ATS-style issues for red-flag testing.
- `Job_Descriptions/` - 3 synthetic JDs in DOCX and TXT formats.
- `Instructions/` - local setup and end-to-end demo guide.

These names, companies, emails, phone numbers, domains, and project details are fictional/demo-only.
